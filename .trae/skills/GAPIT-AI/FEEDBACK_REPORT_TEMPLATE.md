# GAPIT AI 反馈报告模板

本文件是 GAPIT AI（GAPIT5）反馈报告的统一格式。所有反馈必须按照此结构整理，保证格式一致、互不重复。

## 命名规则

反馈报告文件名固定为：

```
GAPIT_AI_feedback_YYYYMMDD_NNN.md
```

其中：

- `GAPIT_AI_feedback` 是贯通不变的前缀。
- `YYYYMMDD` 是报告日期，例如 `20261015`。
- `NNN` 是当日的三位流水号，从 `001` 开始依次递增，例如 `001`、`002`。

名称 + 日期 + 编号三者组合保证全局唯一，任何两份反馈都不会重名。示例：`GAPIT_AI_feedback_20261015_001.md`。

## 报告结构

每份报告包含以下小节，顺序固定，不得增删或改名。

```markdown
# GAPIT AI 反馈报告

**反馈编号**: GAPIT_AI_feedback_YYYYMMDD_NNN
**报告日期**: YYYY-MM-DD
**反馈者**: [姓名/昵称]
**技能版本**: [例如 v1.0-beta.1.3]

## 用户需求
[用户提出了什么分析任务、问题或需求，期望技能帮他完成什么]

## 使用体验
[用户使用这个技能/包的真实体验，包括顺畅的部分，以及遇到的报错、卡顿、理解障碍等]

## 问题与建议
[用户遇到的具体问题，以及用户提出的改进建议]

## 功能代码修改
[本次反馈是否涉及 GAPIT 代码改动；若涉及，记录修改的函数名、位置、原因、修改前后的对比；未涉及则填「无」]

## 处理状态
- 状态：[待处理 / 处理中 / 已解决]
- 优先级：[高 / 中 / 低]
```

## 填写要求

- 「用户需求」和「使用体验」是必填核心，任何反馈都不得省略。
- 「功能代码修改」一节固定保留。本次涉及代码改动时，必须如实记录修改的函数名、所在位置、修改原因和修改前后对比；未涉及改动时填写「无」。
- 报告正文语言跟随反馈者的语言：英文用户写英文，中文用户写中文，但小节结构与顺序保持不变。
- 每份报告只对应一条反馈，不把多条反馈合并进同一个文件。

## 存放位置

生成的反馈报告统一放入工作区根目录的 `feedback_data/reports/` 文件夹。
